# V70.3.9 Profile Management

Migration: `supabase-migration-v70.3.9-profile.sql`

Script: `profile-v70.3.9.js`

The profile module stores editable user/business fields in `public.profiles`:
- full_name
- business_name
- phone
- business_address
- logo_url

Password changes use Supabase Auth email reset and do not store passwords in `profiles`.

UI integration requires a profile view container with id `profileView` or attribute `data-profile-view`, and loading `profile-v70.3.9.js` after the Supabase client.
